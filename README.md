## 🚀 Some things I've built

### [Agora](https://github.com/1dieci0/agora)

A Discord-inspired real-time communication platform built from scratch.

**React + TypeScript · Go · WebSockets · SQLite**

Authentication, servers, channels, realtime messaging, direct messages, mentions, notifications and voice presence.

### [StreamShare](https://github.com/1dieci0/streamshare)

A low-latency screen streaming system built around **Rust and QUIC**.

**Rust · QUIC · H.264 · FFmpeg · NVENC**

Screen capture → hardware encoding → QUIC datagrams → frame reassembly → decoding.

The project explores things like packetization, keyframes, backpressure, frame dropping and the trade-off between latency and reliability.

### [Bird Species Classifier](https://github.com/1dieci0/bird-species-classifier)

A computer vision project using transfer learning to classify **200 bird species**.

**Python · PyTorch · ResNet-18**

71.61% test accuracy on the CUB-200-2011 dataset.
